# Walk With Reya

Мобилно приложение (React Native + Expo SDK 54, JavaScript) за разходки с куче.

## Какво прави

- Старт / край на разходка
- GPS проследяване (и на заден план) + маршрут на картата
- Жива нотификация с разстояние и бутон „Край“
- Премахване на нотификацията = край на разходката
- Приблизителни калории и съвети
- История на разходките

## Стартиране

```bash
npm install
npx expo start
```

За пълно фоново следене (background location + надеждни нотификации) е нужен **development/production build**, не само Expo Go:

```bash
npx expo run:android
```

## Бележка за калориите

Стойностите са ориентировъчни и не са медицински/ветеринарен съвет.
